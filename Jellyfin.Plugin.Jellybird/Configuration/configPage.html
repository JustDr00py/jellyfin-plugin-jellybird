Jellybird connection

jellybird syncs on its own schedule (see its sync.interval config, default 10 minutes). The "Trigger Sync" scheduled task under Dashboard → Scheduled Tasks → Jellybird only asks jellybird to sync right now — it isn't required for jellybird to function.

Docker compose example: http://jellybird:8097 (compose service name). Bare-metal/LAN example: http://192.168.1.50:8097.
Matches jellybird's own server.token config. Leave blank if jellybird has no token set (auth disabled).
Pre-selects the provider on the Search tab. jellybird still treats this as an optional preference, not a restriction.

Search TMDB and add results to your debrid cloud via jellybird. jellybird picks them up on its next sync.
